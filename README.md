# Tutoría Fácil UTA — Prueba HCI Grupo 4

Prueba práctica integradora del primer parcial — Interacción Humano Computador.
Diseño desde cero de un sistema web/móvil para reservar tutorías académicas.

## Problema

La Facultad coordina tutorías por WhatsApp, hojas de cálculo y agendas personales.
El estudiante escribe al docente, espera respuesta, propone horarios y solicita
confirmación; reprogramar implica otra conversación desde cero. No existe un sistema
interactivo unificado.

**Problema de diseño:** ¿Cómo permitir que un estudiante reserve o reprograme una
tutoría desde un teléfono, con claridad, bajo esfuerzo cognitivo, prevención de
errores y acceso mediante teclado o tecnologías de apoyo?
